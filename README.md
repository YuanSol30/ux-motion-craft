# UX Motion Craft

A portable agent skill built from 20 UX and animation principles and 20 ways to improve generic AI designs, supplied by James Yuan.

The skill supports interface creation, visual refinement, interaction design, and evidence-based reviews. It preserves all 40 original topics and adds practical applications, boundaries, and verification guidance. It has no executable dependencies.

## Contents

- [`SKILL.md`](SKILL.md): a self-contained skill with the working approach, all 40 principles, practical applications, boundaries, and verification guidance.

## Use

Copy `SKILL.md` into a folder named `ux-motion-craft` in your agent's supported skill directory. For Codex, use a project `.agents/skills/ux-motion-craft/SKILL.md` path or your personal `~/.codex/skills/ux-motion-craft/SKILL.md` path. Reload the skill list or start a new session if required by your client.

Example prompts:

```text
Use $ux-motion-craft to review this booking page. Report findings without editing it.

Use $ux-motion-craft to improve this dashboard's hierarchy and loading feedback.

Use $ux-motion-craft to refine this modal's motion and reduced-motion behavior.
```

Automatic discovery remains enabled by default in clients that support it. This GitHub repository does not by itself install or activate the skill in ChatGPT.
